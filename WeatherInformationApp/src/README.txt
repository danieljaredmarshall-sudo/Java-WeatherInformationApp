
Weather Information App - README

Project Name:
Weather Information App

Language Used:
Java

GUI Used:
Java Swing

API Used:
OpenWeatherMap API

Description:
This is a Java Weather Information App. The user enters a city name, chooses the unit type, and clicks the search button. The app then shows the current weather information for that city.

How to Run the App:

Open the project in NetBeans.
Open the WeatherApp.java file.
Make sure the OpenWeatherMap API key is inside the code.
Run the program.
Type a city name, for example Durban.
Choose Celsius / m/s or Fahrenheit / mph.
Click Tell Me The Weather.

Features:

The app gets real weather data from OpenWeatherMap.
The user can enter a city name.
The app shows temperature, humidity, wind speed, and weather condition.
The app shows a short-term forecast.
The user can switch between Celsius and Fahrenheit.
The app shows weather status such as CLOUD / Cloudy or RAIN / Rainy.
The app saves recent searches with the date and time.
The app gives error messages if the city is empty, invalid, or if the API request fails.
The background changes depending on the time of day.

Conclusion:
This Weather Information App meets the assignment requirements because it uses a Java Swing GUI, connects to a weather API, displays real-time weather information, shows a forecast, supports unit conversion, handles errors, tracks search history, and changes the background.
